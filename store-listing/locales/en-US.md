## Description

```text
Developer work is full of small values that do not belong in a source repository—and do not need a cloud service of their own. moeSegFault Scrap gives tokens, passwords, account IDs, endpoints, and other short text a quiet home on your PC.

Create scopes for projects, environments, or services, then search one, several, or every scope. Every result keeps its scope visible, so duplicate keys from different environments remain unambiguous. Choose exact, fuzzy, or regular-expression matching, with optional case sensitivity.

Secrets can be masked by default, while ordinary fields can remain visible. Both display choices use the same encrypted storage. Showing or hiding a value while editing never changes how the saved record will appear. A masked value can be revealed temporarily or copied directly; after a copy, Scrap attempts to clear the clipboard only if its contents have not changed.

Use the desktop app for quick finding and copying. The bundled scrap command line fits scripts and pipelines, while sharing the same local data source. No cloud account is required, and Scrap itself does not upload your records to a remote service.

The interface supports Simplified Chinese and English, follows the Windows appearance by default, and also offers explicit light and dark themes.

Scrap is a local field store. It does not provide cloud sync, cross-device recovery, or browser autofill. Back up the local data together with the relevant operating-system key material.
```
