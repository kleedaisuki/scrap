## Short description

```text
把令牌、密码和短文本留在本机，也让它们在需要时立刻可用。Scrap 带来跨 scope 检索、清晰的遮罩控制，以及可组合的命令行。
```

## Description

```text
开发工作中总有一些值，不适合写进代码仓库，也不值得为它们启动一整套云服务。moeSegFault Scrap 给令牌、密码、账号 ID、端点和其他短文本一个安静的本地位置。

为不同项目、环境或服务建立 scope，再从一个、多个或全部 scope 中搜索 key。搜索结果始终标明归属；即使同名 key 分散在不同环境，也不会混淆。你可以使用精确、模糊或正则匹配，并按需区分大小写。

需要保存秘密时，可让记录默认遮罩显示；保存普通字段时，也可以直接显示。两种显示方式使用相同的加密存储。编辑时临时显示或隐藏 value，不会改变保存后的显示策略。遮罩记录可以临时显示，也可以直接复制；复制后，Scrap 会在剪贴板内容仍未变化时尝试清理它。

桌面应用适合日常查找和复制。随包安装的 scrap 命令行适合脚本与管道；两者共享同一个本地数据源。无需云账户，Scrap 本身不会把记录上传到远程服务。

界面支持简体中文和英语，可跟随系统，也可选择浅色或深色主题。

Scrap 是本地字段存储工具，不提供云同步、跨设备恢复或浏览器自动填充。请自行备份本地数据及相关系统密钥材料。
```
